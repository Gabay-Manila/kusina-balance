# KusinaBalance — 生活献立帳

マニラ在住のフィリピン高齢者（日本人）向けに、**現地（パレンケ・スーパー）で手に入る食材**を使って、健康状態に配慮した1週間の献立を自動生成するアプリです。

作る人（フィリピン人スタッフ・お手伝いさん）が読みやすいよう、料理名・材料・作り方をワンタップで日本語⇄英語に切り替えられます。

🔗 **公開URL**: https://kusina-balance.vercel.app/

---

## コンセプト

- 年代・持病に応じて「減塩」「マグネシウム補給」「低脂質」「低プリン体」などのケア方針を設定でき、それに沿った献立が自動編成される
- 使用食材はすべてフィリピンのローカルスーパー・パレンケ（青空市場）で揃うもの（Kangkong、Sayote、Malunggay、Bangus など）
- 「たまに日本の味も楽しむ」設定で、卵焼きや親子丼などの和食（現地食材でアレンジしたもの）も時々織り交ぜられる
- 買い物帳は献立から食材を自動集計し、チェックリストとして使える
- ワンタップで献立表＋買い出しリストをテキストとしてクリップボードにコピーでき、Google KeepやMessengerに貼り付けて実際の買い物・調理の場で使える

## 主な機能

| タブ | 内容 |
|---|---|
| **週間献立** | 月〜日、朝・昼・夜の献立をカード表示。タップで料理を個別に変更可能。マグネシウム補給達成度をヘッダーで可視化 |
| **買い物帳** | 1週間の献立から食材をカテゴリ別（青果／精肉／魚介／豆腐・卵／乾物・調味料／主食・パン／乳製品）に自動集計。チェックを入れると打ち消し線、リセットで一括クリア |
| **料理帳** | 全24品のレシピ集。材料・ワンポイントアドバイス・「作り方を見る」で開閉する3ステップの手順を掲載。すべて／Mg高含有／朝食／昼食／夕食でフィルタ可能 |
| **条件設定** | 年代（60代／70代／80代／一般）、重点ケア項目（減塩・Mg補給・低脂質・低プリン体）、たまに日本の味、除外したい食材（ゴーヤ・甲殻類・豚肉・魚介・辛味）を設定 |

### そのほかの機能

- **EN⇄JP切り替え**（ヘッダー右上）：料理名・材料・手順・UI文言すべてが連動して切り替わる
- **テキストコピー**（ヘッダーのクリップボードアイコン）：週間献立＋買い出しリストを整形テキストでコピー
- **一括生成**：現在の条件設定に沿って献立をランダム再編成
- **PWA対応**：ホーム画面に追加してアプリのように起動可能（マニフェスト・アイコンをHTML内にBase64で埋め込み、外部ファイル不要）
- **オフラインキャッシュ**：簡易Service Workerでオフライン時もある程度動作
- **ブランド音**：操作時に437Hz統一の短いトーンを再生（Yoshida EdTech Works共通仕様）

## 技術構成

単一HTMLファイルのPWA、ビルドステップなし。Yoshida EdTech Works共通開発方針に準拠。

- **フレームワークなし**（Vanilla JS）＋ [Tailwind CSS](https://tailwindcss.com/)（CDN）
- アイコン: [Lucide](https://lucide.dev/)（CDN、CDN未読込時も落ちないようフォールバック処理あり）
- フォント: Shippori Mincho（見出し・数字）／ Zen Kaku Gothic New（本文）
- データ永続化: `localStorage`（サーバー・DBなし、端末ごとに保存）
- 音: Web Audio API（437Hz統一トーン）
- 画像: すべてBase64埋め込みのPNG／SVG（外部画像ファイルなし）

### localStorageキー

| キー | 内容 |
|---|---|
| `kusina_banana_profile` | 年代・ケア設定・除外食材 |
| `kusina_banana_sched` | 現在の週間献立（曜日×食事タイプ→料理ID） |
| `kusina_banana_checks` | 買い物帳のチェック状態（食材の日本語名をキーに保存、言語切替に影響されない） |
| `kusina_banana_lang` | 表示言語（`ja` / `en`） |

## デプロイ

GitHub + Vercelでのデプロイを想定（単一 `index.html` をそのままルートに配置するだけ）。

```bash
git add index.html
git commit -m "index.htmlを更新：（変更内容を簡潔に）"
git push
```

Vercelに連携済みのリポジトリであれば、pushと同時に自動デプロイされます。

- 本アプリは [Yoshida EdTech Works 共通開発プロンプト](./共通開発プロンプト.md) のデザイントークン・コンポーネントパターンに準拠しています（アクセントカラー: バナナ黄 `#E0B23A` = 案内・生活ガイド系統）
- コンテンツ制作フロー: Gemini（大賢者）が献立・レシピ内容を下書き → Claude（ソネットくん）が共通プロンプトの基準で校正・実装
- **本番配布前の注意**: レシピ内容（特に食材の分量・調理法）は、対象言語（英語／タガログ語）のネイティブ・現場スタッフによる目視チェックを推奨します
- 料理データを追加する際は、`DISHES` 配列に以下を含めてください: `id` / `name`（英語名）/ `nameJa` / `mealType` / `mgLevel` / `tags` / `avoidTags` / `ingredients`（`item` `qty` `itemEn` `qtyEn` `cat`）/ `tip` `tipEn` / `steps` `stepsEn`
